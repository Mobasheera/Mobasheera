### 🔦 Featured Work

**[Atomberg BLDC IR Remote](https://github.com/Mobasheera/Atomberg-BLDC-IR-Remote)**
Reverse-engineered the infrared protocol used by Atomberg BLDC ceiling fan remotes — verified the published NEC commands, found and corrected errors in them, and discovered undocumented ones. Built a native Android remote (`ConsumerIrManager`, no Bluetooth/Wi-Fi/internet) that replicates the original hardware remote, open-sourced end to end.
`Java` `Android` `ConsumerIrManager` `NEC IR Protocol`

**[TetrisPDF](https://github.com/Mobasheera/TetrisPDF)**
A fully playable Tetris — inside a PDF. Python generates the document; embedded JavaScript handles collision detection, rotation, and keyboard input. No game engine, just PDF internals pushed further than they're meant to go.
`Python` `JavaScript` `Acrobat JavaScript`

**[GiftGenius](https://github.com/Mobasheera/GiftGenius)**
Built in a 24-hour hackathon: an AI gift-recommendation platform using RAG to match gifts to interests, budget, and occasion. My part was database design and deployment on a Node/Express/MySQL (Railway) stack.
`Node.js` `Express` `MySQL` `RAG`
